# Amhar deployment of OpenPost

This public fork of [getopenpost/openpost](https://github.com/getopenpost/openpost) holds Amhar's deploy config and documentation. Production code is the pinned upstream release binary, not a build of this monorepo.

- Integration branch: `architect/setup`
- Production branch: `main` (release PRs only, after Ahmad's UAT)
- Host: Replit Reserved VM (0.5 vCPU / 2 GB), domain `https://post.amhar.co`
- Docs: [docs/amhar/README.md](docs/amhar/README.md)

Do not put secrets in this repository.
